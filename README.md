# ModKillAddon

给 **Degrees of Lewdity 0.5.11.9（简中）** 添加「击杀机制」的 ModLoader 模组。

## 主要功能

- **击杀机制**：无名敌人 138 个入口；6 个具名 NPC（Bailey / Whitney / Eden / Black Wolf / Gwylan / Avery）完整死亡线
- **「走开」**：战斗页可无代价退出
- **附属功能**：街头事件改造、镜子寄生、耳史莱姆「不理它」、家政课恶作剧双选项

## 安装

1. 从 [Releases](../../releases) 下载 `ModKillAddon.mod.zip`
2. 在游戏的 Mod 管理器里导入

## 依赖

| Mod | 版本约束 |
|---|---|
| ModLoader | \`^2.0.0\` |
| ModI18N | \`>=1.0.0a\` |
| GameVersion（游戏本体） | \`=0.5.11.9\`（精确匹配） |

## 自动更新

游戏加载完成后会自动检查本仓库的 Release，有新版本会弹窗提示并可一键更新。
