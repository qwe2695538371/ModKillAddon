# ModKillAddon

给 **Degrees of Lewdity**（中文本地化「欲都孤儿」，0.5.11.9）添加**击杀机制**的 ModLoader 模组。

> **仅限 18 岁以上使用。** 本模组与原作均为面向成年人的虚构作品。

---

## 这是什么

原作里 NPC 是打不死的。这个模组让它们可以被杀死 —— 而且死了就是真的死了，相关剧情线会跟着改写。

### 无名敌人

战斗页最上方多出「**杀死他／杀死她**」（按敌人代词变化），按敌人类型走不同演出：

> 野兽 / 无名人类 / 群战 / 触手 / 虫群 / 史莱姆 / 霸凌者 / 水虫群 / 容器蛆虫……

共 **138 个入口**，覆盖森林、街头、校园、下水道、湖泊、狼穴、寺庙花园等几乎所有战斗场景。

### 具名 NPC：杀死之后，他会从世界里消失

**6 个具名 NPC 可以真正被杀死**，死亡不是一次演出——相关剧情线会整体改写：

| NPC | 死后世界的变化 |
|---|---|
| **Bailey 贝利** | 租金永久停收；孤儿院、宅邸、监狱、农场等上百处剧情分支改写 |
| **Whitney 惠特尼** | 校园霸凌循环终止 |
| **Eden 伊甸（猎人）** | 森林不再有猎人追你，**他的小屋归你**（住宿 / 壁炉 / 翻柜 / 菜园 / 泉水） |
| **Black Wolf 黑狼** | 可以**取而代之**，成为狼群首领 |
| **Gwylan 格威岚** | 猎杀线与相关剧情消失（三种死法各有演出） |
| **Avery** | 约会线终止 |

另有教程假人、租金战、绑架线绑匪、狼猎人团伙等半具名击杀。

### 附属功能

- **「走开」** —— 战斗里可以无代价退出（146 处），不是「逃跑」，是「退出这一段」
- **街头事件改造** —— 暴露类 12 个事件全部有保底躲藏；名声议论事件按淫乱度分三档；补齐漏掉的战斗页
- **镜子寄生** —— 24 个部位 × 4 类型寄生全显示，可自行摘除（15 分钟 + 诡术判定）
- **耳史莱姆** —— 命令你时多了「不理它」
- **挣扎反击** —— 被吞、被缠住时的对抗加了击杀
- **家政课恶作剧** —— 吸尘器 / 绊倒 / 水槽各有「以牙还牙」与「避开」两种应对

## 安装

1. 从 [Releases](https://github.com/qwe2695538371/ModKillAddon/releases) 下载 `ModKillAddon.mod.zip`
2. 在游戏的 **Mod 管理器**里导入并启用
3. 重启游戏

### 依赖

| Mod | 版本约束 |
|---|---|
| ModLoader | `^2.0.0` |
| ModI18N（中文汉化） | `>=1.0.0a` |
| 游戏本体 | **`=0.5.11.9`**（精确匹配，换版本即失效） |

## 自动更新

装好之后，游戏加载时会自动检查本仓库的 Release，有新版本会弹窗提示，点一下即可自动下载安装并重载。
